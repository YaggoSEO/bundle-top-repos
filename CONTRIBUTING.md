# Guía de Contribución: Añadir Repositorios

¡Gracias por querer contribuir a esta colección de herramientas imprescindibles!

Para que nuestra colección en **Bundle Top Repos** se mantenga limpia y de alta calidad técnica, seguimos unas pocas pero estrictas reglas a la hora de recibir Pull Requests con nuevos recursos:

### Pasos para añadir un repositorio:

1. **Revisa que el Repositorio no esté listado:** Haz una búsqueda rápida en el `README.md` (con Ctrl+F o CMD+F) antes de proponerlo.
2. **Abre un Pull Request:** Realiza un Fork de este repositorio y clona esa copia en tu entorno local, si tienes permisos puedes hacer directamente un clon con tu cuenta.
3. **Comodidad de Lectura:** Busca una categoría adecuada para añadir el repositorio. Por favor, añádelo en formato bullet list (`-`) utilizando un formato en negrita para el nombre (enlazado al repositorio original), seguido de una explicación con la máxima información relevante sobre el repo.
  
   El formato debe ser:
   `- [**NombreDelRepo**](enlace_al_repo): Breve explicación de por qué es importante o qué problema soluciona.`

4. **Si el proyecto es innovador y no encaja en las categorías actuales:** ¡No tengas miedo!, puedes abrir una nueva sección del README sugeriendo ese tipo de herramientas (`### 🆕 Nueva Categoría`).

### Criterios de Calidad
- El repositorio debe estar activamente mantenido.
- Se valora muy positivamente que solucione una necesidad clara del equipo de desarrollo, DevOps o administradores de base de datos.
- Añadir un repositorio con alta popularidad de comunidad o muy buena documentación facilita su aprobación rápida.

¡Muchas gracias por ayudar a mejorar la caja de herramientas de desarrollo del equipo!
